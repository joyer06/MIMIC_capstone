# MIMIC_capstone
I implemented 30-day hospital readmission prediction using MIMIC-IV clinical Database demo as a capstone project. This project consist of three assignments to complete business report along with CRISP-DM.
The description below is about assigment 3.

# ICU Readmission Prediction - Assignment 3

## Overview
This assignment wraps up Assignments 1 and 2 into a business report. The report summarizes the EDA and modeling results from the earlier assignments and frames them for a hospital audience, with recommendations on risk screening and resource allocation. No new analysis code is produced in this assignment. The previous notebooks are included as reference material.

## Repository Structure
This repository is organized as follows:

   `hosp/`: Hospital related data tables used in the previous assignments (e.g., `patients.csv`, `admissions.csv`, `diagnoses_icd.csv`, `labevents.csv.gz`).

   `icu/`: ICU related data tables (e.g., `icustays.csv.gz`, `chartevents.csv.gz`).

   `Reference_Code/`: Copies of the Assignment 1 and Assignment 2 code folders, kept for reference. The business report draws its feature importance results from the Assignment 2 notebook.
       1) `Hwang_Soyeon_Assignment1_Code/`: EDA notebook and README from Assignment 1.
       2) `Hwang_Soyeon_Assignment2_Code/`: Data preparation and modeling notebook and README from Assignment 2.

   `requirements.txt`: Python dependencies used by the reference notebooks.

   `README.md`: This file.
